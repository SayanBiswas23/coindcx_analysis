================================================================================
SQL TECHNIQUES DEMONSTRATED
================================================================================

✓ Window Functions
  └─ ROW_NUMBER, LAG, SUM OVER for rates and rankings
  └─ Example: ROUND(100.0 * kyc_approved / NULLIF(signups, 0), 1)

✓ Common Table Expressions (CTEs)
  └─ Multi-stage aggregations for complex logic
  └─ Example: WITH funnel_base AS (...), validated_counts AS (...)

✓ Cohort Analysis
  └─ Date bucketing to track retention over time
  └─ Example: DATE_TRUNC('month', executed_at) AS cohort_month

✓ Conditional Aggregations
  └─ CASE WHEN for counting users by status
  └─ Example: COUNT(DISTINCT CASE WHEN kyc_status = 'APPROVED' THEN user_id END)

✓ Self-Joins
  └─ For tracking users across multiple time periods
  └─ Example: Joining trades table to itself for buyer/seller analysis
